## 🛠️ Prerequisites & Getting Started

### 1. Install Python 3.10+
Download and install the latest Python 3 release from [python.org](https://www.python.org/downloads/). Ensure you check **"Add Python to PATH"** during Windows installation.

Verify your installation:
```bash
python --version
# Expected: Python 3.10.x or higher (Python 3.12+ recommended)
```

### 2. Recommended IDE Setup
- **Visual Studio Code** or **Cursor** / **PyCharm**
- Recommended Extensions:
  - **Python** (Microsoft)
  - **Pylance** (Type checking & IntelliSense)
  - **Ruff** (Fast linting and code formatting)

### 3. Create a Dedicated Virtual Environment
In your workspace, create and activate a virtual environment:

**On Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**On macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 🎯 How to Use This Course

1. **Read & Understand**: Study the module documentation sequentially.
2. **Execute Every Code Snippet**: Type out the code in your terminal or IDE—do not just read passively.
3. **Solve the Practice Questions**: Complete the conceptual and coding exercises at the end of each module before checking the answers.
4. **Build the Activity Project**: Each module includes a hands-on activity. Implement your own solution according to the requirements specifications.
5. **Level Up**: Move on to the next module and build upon your growing foundation.
